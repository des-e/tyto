# Политика конфиденциальности Tyto

Расшифровка речи в Tyto всегда выполняется на вашем компьютере: аудио и видео никуда не отправляются.

Текст расшифровки уходит наружу, только если вы делаете саммари, темы или ИИ-разбор: по кнопке в записи или включив саммари для каждой новой записи в настройках. В этом случае текст передается либо на сервер Tyto по коду доступа (Tyto ИИ), либо провайдеру ИИ по вашему собственному ключу. С Ollama на вашем компьютере текст никуда не уходит.

Сервер Tyto не хранит тексты дольше, чем нужно для обработки запроса, и не использует их ни для чего другого.

Если вы не пользуетесь саммари, темами и ИИ-разбором, текст не покидает компьютер.

Сборки Tyto собираются без ключа аналитики, поэтому никакая статистика использования не отправляется. Запись с телефона через сервер-ретранслятор в Tyto отключена.

Модели для расшифровки скачиваются с Hugging Face и GitHub по вашему запросу. Приложение основано на Vibe (MIT).
