# Политика конфиденциальности Tyto

Расшифровка речи в Tyto всегда выполняется на вашем компьютере: аудио и видео никуда не отправляются.
Запись с телефона (через сервер-ретранслятор) в Tyto отключена.
Текст расшифровки уходит наружу только тогда, когда вы сами запускаете темы или сводку.
В этом случае он передаётся либо провайдеру ИИ по вашему собственному ключу, либо на сервер Tyto по коду доступа.
Сервер Tyto не хранит тексты дольше, чем нужно для обработки запроса, и не использует их ни для чего другого.
Если вы не пользуетесь темами и сводкой, текст не покидает компьютер.
Сборки Tyto собираются без ключа аналитики, поэтому никакая статистика использования не отправляется.
Приложение основано на Vibe (MIT), модели для расшифровки скачиваются с Hugging Face и GitHub по вашему запросу.
