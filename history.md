# Tyto — история решений

## 2026-10-25 — форк

- Форк `thewh1teagle/vibe` → `des-e/tyto` (публичный). База: тег `v3.2.2` (23eae78). На момент форка upstream main был на 3 коммита впереди тега: стартуем со стабильного релиза, а не с головы.
- Почему форк, а не своё приложение: Денис протестировал Vibe 3.2.2, интерфейс и функции устраивают; не хватает своих фич (темы с таймкодами, «Наш сервис», говорящие по умолчанию). Полный разбор: `docs/superpowers/specs/2026-10-25-tyto-design.md`.
- Предшественники: транскрибатор v0.20 (`G:/bitrix-projects/transcribe/`) остаётся у текущих пользователей; июльский план pywebview (`G:/bitrix-projects/transcribe-desktop/`) — архив.
- Принцип: свои изменения изолированы (`tauri.tyto.conf.json`, `tyto-release.yml`, `src/lib/tyto/`, `scripts/tyto/`), чтобы подтягивать upstream без боли.

## 2026-10-26 — 0.1.2: визуальный язык, тексты, прокси

- Выпущен v0.1.2 (план `docs/superpowers/plans/2026-10-25-tyto-visual-language.md`, дизайн `docs/design/2026-10-25-tyto-visual-language.md`): строгий минимализм, сова, своя система кнопок, экспорт 4+4 формата без CSV, свои тексты, ИИ через прокси-сервисы, язык распознавания по умолчанию «авто».
- Денис принял скриншоты; на экране первого запуска оставлена одна сова — идущая (статичная над заголовком убрана).
- Решения по ходу:
  - copy.test.ts — единственный источник закреплённых строк; другая формулировка меняется вместе с тестом.
  - Ошибка GPU простыми словами: «Не удалось запустить на видеокарте, расшифровываем на процессоре. Это медленнее.»
  - Блок имени файла в плеере убран (как в макете), «Показать в папке» вернулось иконкой.
  - Одноразовая миграция языка en→auto, если en не выбирался явно (нет в недавних); флаг `tyto.langAutoMigrated`, не падает на испорченном конфиге.
  - Сова моргает один раз по завершении расшифровки (для каждой задачи).
- Отложенная полировка (не блокирует): скругления 16px на части карточек (resummarize/retranscribe/drop-modal/summary-view); writeConfig вне try в миграции; крестик настроек не выровнен на «Общие»; поля настроек 36px вместо 32; кнопки «Изменить промпт…» обрезаются; «Записать» без нажатого состояния; иконка трея на mac не template; WKWebView (mac) не проверен глазами; тосты на ширине <600px.
