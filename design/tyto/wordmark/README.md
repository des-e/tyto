# Tyto: словесный знак

Направления логотипа. Сравнение всех вариантов: `index.html` (открывается в браузере, все SVG внутри страницы). Выбрано: v1 Ушки + v5 Глаз (папка `v7-ushki-glaz/`), из них вариант 7c Тихий, его доработка в папке `v8-tikhiy/`.

В каждой папке:
- `wordmark.svg`: надпись, переведенная в кривые;
- `lockup-horizontal.svg`: сова и надпись;
- `lockup-small.svg`: версия для боковой панели (блок 28 px высотой, заглавная около 20 px: начертание плотнее, трекинг шире, уши глубже, зрачок крупнее, сова без лапок).

Все файлы одноцветные, цвет задается через `currentColor`.

## Тихий, доработка (v8, текущий выбор)

- **8a Плотнее** (`v8-tikhiy/a-plotnee/`): Только ритм: o придвинута к t, просветы y-t и t-o теперь на глаз равны, T-y чуть плотнее. Толщины как в 7c.
- **8b Тоньше кольцо** (`v8-tikhiy/b-tonkoe-koltso/`): Тот же ритм, кольцо глаза тоньше примерно на шестую часть, зрачок чуть меньше. Буква o перестает быть самой темной в слове.
- **8c Легче целиком** (`v8-tikhiy/c-legche/`): Тот же ритм и тонкое кольцо, плюс все слово примерно на 10% легче. Самый тихий вариант, ближе к весу текста интерфейса.

Малые версии всех трех держат кольцо толще, чем крупные, иначе при заглавной 20 px оно тонет; уши в малой версии подняты над линией заглавных.

## Ушки + Глаз (v7)

- **7a Основа** (`v7-ushki-glaz/a-osnova/`): оптимизирован для: узнаваемость и преемственность с v1. Буквы y и t из Outfit, T и o нарисованы: уши на перекладине и глаз вместо o. Шрифт: Outfit 500 (малая версия 600) для y и t; T и o нарисованы; SIL Open Font License 1.1.
- **7b Рисованный** (`v7-ushki-glaz/b-risovannyy/`): оптимизирован для: единство линии с иконкой. Все буквы построены вручную одной толщиной линии, как в v5, и получили заглавную T с ушами. Шрифт: Без исходного шрифта, построение вручную; Собственная отрисовка.
- **7c Тихий** (`v7-ushki-glaz/c-tikhiy/`): оптимизирован для: спокойствие и читаемость в тексте. Те же детали, но сдержаннее: уши мельче, зрачок маленький, начертание легче, разрядка шире. Шрифт: Outfit 430 (малая версия 560) для y и t; T и o нарисованы; SIL Open Font License 1.1.
- **7d Плотный** (`v7-ushki-glaz/d-plotnyy/`): оптимизирован для: мелкие размеры: боковая панель, значок, трей. Рисованная версия для мелких размеров: линия толще, x-высота больше, уши глубже, зрачок крупнее, просветы шире. Шрифт: Без исходного шрифта, построение вручную; Собственная отрисовка.

## Прежние направления

- **v1 Ушки** (`v1-ushki/`): Геометрический гротеск, у которого перекладина T нарисована заново по силуэту головы совы с иконки: острые уши по краям и мягкий прогиб к центру. Шрифт: Outfit, начертание 500 (Medium); буква T нарисована заново; SIL Open Font License 1.1.
- **v2 Редакция** (`v2-redaktsiya/`): Контрастная антиква в оптическом размере 144: спокойный редакционный голос, как у хорошего издательства. Шрифт: Fraunces, оси wght 470, opsz 144, SOFT 0, WONK 0 (малая версия: wght 560, opsz 20); SIL Open Font License 1.1.
- **v3 Мягкий** (`v3-myagkiy/`): Округлый гротеск с мягкими окончаниями, которые повторяют скругленный силуэт совы. Шрифт: Nunito, начертание 700 (малая версия 780); SIL Open Font License 1.1.
- **v4 Протокол** (`v4-protokol/`): Моноширинный шрифт и блочный курсор после слова: расшифровка как текст, который печатается прямо сейчас. Шрифт: IBM Plex Mono Medium; курсор добавлен; SIL Open Font License 1.1.
- **v5 Глаз** (`v5-glaz/`): Буквы нарисованы с нуля одной толщиной линии. Шрифт: Без исходного шрифта: буквы построены вручную из прямоугольников, диагоналей и окружностей; Собственная отрисовка, лицензия шрифта не нужна.
- **v6 Связка** (`v6-svyazka/`): Плотный Inter Tight строчными, родственник интерфейсного Inter. Шрифт: Inter Tight, начертание 600 (малая версия 660); лигатуры ty и to нарисованы; SIL Open Font License 1.1.

## Шрифты

Исходные шрифты лежат в `_fonts/` вместе с текстами лицензий (все SIL OFL 1.1, источник: репозиторий google/fonts). Варианты 7b, 7d и v5 нарисованы без шрифта. Для использования логотипа шрифты не нужны: знаки уже в кривых.
