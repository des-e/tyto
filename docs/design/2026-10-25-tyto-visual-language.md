# Tyto: визуальный язык и тексты

**Дата:** 2026-10-25 · **Статус:** предложение, код не менялся
**Макеты:** `G:/bitrix-projects/transcribe-desktop/.superpowers/brainstorm/1669-1792912113/content/tyto-visual-language-v2.html` (актуальная версия; v1 рядом, `tyto-visual-language.html`). Было → стало для пяти экранов, система кнопок, список отличий с галочками.

**v2 (2026-10-25), по замечаниям владельца:** в экспорте убран CSV, форматы 4 + 4 в выровненной сетке; «Оформление» в экспорте на одной сетке строк; нижняя полоса боковой панели и плеер одной высоты на одной линии. Плюс аудит отступов всех макетов: все значения приведены к шагу 4 px (шкала ниже).

## Почему сейчас «как Vibe»

Первый рестайл поменял цвета, но оставил все, что делает Vibe узнаваемым: форму и размер кнопок (44 px, полужирные, радиус 12, «таблетки»), КАПС-подписи («НАСТРОЙКА», «НЕДАВНИЕ», «ФОРМАТ»), пунктирную карточку для файла, карточки-группы в настройках, иконки-вкладки «папка / микрофон / ссылка», плеер с круглой кнопкой, тексты с эмодзи и восклицаниями. Узнаваемость сидит в форме и голосе, а не в цвете. Ниже правки именно формы и голоса.

## Принципы

1. **Тишина вместо украшений.** Один акцент (цвет текста), тонкие линии вместо карточек и теней, без пилюль и пунктира.
2. **Текст встречи главный.** Все вокруг расшифровки тише ее: подписи мелкие и серые, речь крупная и спокойная.
3. **Каждое действие подписано.** Главная кнопка экрана говорит глаголом и объектом («Сохранить PDF»), у иконки всегда есть подсказка.
4. **Деловой спокойный голос.** Коротко, по-человечески, без «!», эмодзи и длинных тире. Говорим, что происходит и что нужно от человека.
5. **Строже, чем Vibe.** Радиусы 6/8/12 вместо 12/16/«таблеток», вес 500 вместо 600, обычный регистр вместо КАПСА.

## Токены

Все токены (включая `--tyto-sp-*` и `--tyto-bar-h: 56px`) живут в `desktop/src/lib/tyto/theme.css` (наш файл, конфликтов при слиянии нет).

### Радиусы

| Токен | Значение | Где |
|---|---|---|
| `--tyto-r-xs` | 4px | мелкие метки: галочки, метки говорящих, теги, клавиши, лист предпросмотра |
| `--tyto-r-sm` | 6px | поля ввода, маленькие кнопки, строки списков, пункты меню, внутренние сегменты |
| `--tyto-r-md` | 8px | обычные и крупные кнопки, карточки выбора, сегменты, тосты |
| `--tyto-r-lg` | 12px | диалоги, окна настроек, блок шагов на первом запуске |
| круг | 50% | только переключатели, радио-кнопки, сова |

`--radius` (shadcn) ставим в `0.5rem`, чтобы `rounded-lg/xl` в общих компонентах сами стали строже. «Таблетки» (`rounded-full`) у кнопок и сегментов убираем.

### Отступы и плотность

Шаг 4 px. Все отступы, зазоры и высоты рядов берутся только из шкалы (v2, после аудита макетов):

| Токен | Значение | Где |
|---|---|---|
| `--tyto-sp-2` | 2px | только внутри контролов и пар «название + описание»: поля сегмента, зазор между пунктами списка, отступ описания под названием |
| `--tyto-sp-4` | 4px | иконка и текст в маленькой кнопке, подпись группы → первый пункт, имя говорящего → реплика, реплики одного говорящего |
| `--tyto-sp-8` | 8px | иконка и текст в кнопке, контрол и его подпись (радио, галочка), подпись группы → контролы, кнопки рядом |
| `--tyto-sp-12` | 12px | поля маленькой кнопки и сегмента, ячейки таблиц, внутри карточки выбора, элементы плеера |
| `--tyto-sp-16` | 16px | поля обычной кнопки, внутренние поля блоков (шаги, тосты по горизонтали), зазоры между блоками внутри группы |
| `--tyto-sp-24` | 24px | поля диалога и предпросмотра, между группами в диалоге, между колонками форматов, между репликами разных говорящих (20 + 4) |
| `--tyto-sp-32` | 32px | поля страницы настроек, лист предпросмотра, отступ перед подзаголовком в настройках |
| `--tyto-sp-48` | 48px | правое поле документа |

Исключения, оставленные сознательно: 28 px левое поле документа и плеера (совпадает с текстом первой вкладки), 20 px поля крупной кнопки, 20 px между репликами, оптические сдвиги в 1-2 px (иконка к первой строке текста).

Ряды: 28 (компактный), 32 (форматы, галочки, пункты меню, поиск, сегменты, select), 36 (кнопки), 56 (нижние полосы: боковая панель и плеер; строки таблицы кнопок; минимум строки настроек, с описанием выше). Поля диалога 24 px, шапка 16 px, подвал 12 px по вертикали. Боковая панель 248 px, ее поля 8 px, текст пунктов, подписей групп и иконки поиска/кнопок на одном левом крае 16 px. Строки с подсветкой (форматы) выносятся на 8 px за край группы, чтобы радио стояли на общем левом крае с подписями.

### Иконки

lucide, 16 px, штрих **1.5** (сейчас 2). Одно правило в theme.css: `svg.lucide { stroke-width: 1.5 }`. В плеере и пустом экране 16-18 px, не больше.

### Движение

`--tyto-ease: cubic-bezier(.23,1,.32,1)`. Нажатие кнопки `scale(.97)` за 150 мс. Диалоги и поповеры 180-200 мс. На действиях с клавиатуры анимации нет. Учитываем `prefers-reduced-motion`.

## Система кнопок

Правка в `components/ui/button.tsx` (мелкий shadcn-файл, апстрим его почти не трогает) плюс несколько правил в theme.css.

| Вариант | Вид | Где используется |
|---|---|---|
| **Главная** (`default`) | фон цвета текста, текст цвета фона | одна на экран/диалог: «Сохранить PDF», «Выбрать файл», «Повторить», «Расшифровать» |
| **Второстепенная** (`outline`, переименовать по смыслу в secondary) | фон страницы, граница 1 px `--line2` | «Экспорт» в панели, «Скопировать текст», «Записать», «Отменить загрузку» |
| **Тихая** (`ghost`) | без фона и границы, текст **цвета текста** (не серый) | «Отмена», «Настройки» в панели, «О программе», пункты меню |
| **Опасная** (`destructive`) | красный фон, белый текст | только кнопка подтверждения в окне «Удалить расшифровку?». В меню удаление красным текстом |
| **Иконка** (`icon`, `iconSm`) | квадрат 32/28, иконка muted, при наведении серая подложка и цвет текста | поиск, вид, закрыть, скрыть панель. Всегда `aria-label` + подсказка |
| Ссылка (`link`) | подчеркивание при наведении | только внутри текста |

**Размеры:** sm 28 px (радиус 6, текст 13, поля 12, отступ иконки 4), md 36 px (радиус 8, текст 14, поля 16, отступ 8), lg 44 px (радиус 8, текст 15, поля 20, отступ 8, только первый запуск и пустой экран). Иконка-кнопка квадратная: 32 × 32 и 28 × 28. Вес 500 везде. Иконка в кнопке 16 px. (v2: радиус lg 10 → 8, чтобы не плодить лишний радиус; отступы приведены к шагу 4.)

**Состояния:**
- Наведение: главная светлеет на 16% (`color-mix` с фоном), второстепенная получает серый фон и более темную границу, тихая и иконка серую подложку.
- Нажатие: `scale(.97)`, 150 мс, `--tyto-ease`.
- Фокус с клавиатуры: `outline: 2px solid var(--foreground); outline-offset: 2px` (вместо полупрозрачного ring).
- Недоступна: серый фон `--muted`, серый текст, граница `--border`, курсор not-allowed. Без `opacity: .5`: полупрозрачная черная кнопка выглядит как нажатая.

**Правила подписей:** глагол + объект; иконка без текста только для общеизвестного (поиск, закрыть, панель); в подвале диалога «Отмена» слева от главной, главная крайняя справа; серого «текста-кнопки» без границы и фона не бывает (как «Отменить» на текущем экране загрузки).

## Первый запуск (загрузка модели)

Сейчас: «НАСТРОЙКА / Загрузка модели... / 60% · Это необходимо только 1 раз 🎉 / Отменить (серый текст)». Не видно, что качается, сколько и зачем, и что после 100% начнется второй файл (полоса сбрасывается в ноль при переходе к модели говорящих, см. `ensureDiarizeModelOnSetup`).

Новая раскладка (колонка 460 px по центру):
1. Сова 40 px.
2. Заголовок «Готовим Tyto к работе».
2а. **Идущая сова** (v3, по просьбе владельца): сразу под заголовком полоса высотой ~56 px, по которой геометрическая сова в профиль ходит вправо и влево (покачивание корпуса + шаги лапок, шаг 0.32 с, проход ~4 с, у края разворачивается). Источник формы: `design/tyto/owl-walk-right.svg`, `owl-walk-left.svg` (рисунок владельца, код пишем свой: inline SVG-компонент `lib/tyto/owl-walk.tsx`, CSS-анимация только transform, `currentColor` для тёмной темы, при `prefers-reduced-motion` сова стоит). Пока идёт загрузка — ходит; на ошибке «Нет подключения» — стоит.
3. Абзац: «Скачиваем модели распознавания речи. Это нужно один раз: дальше Tyto работает без интернета.»
4. Список из двух шагов в рамке 12 px:
   - «1 Распознавание речи / Превращает звук в текст», справа «1,0 из 1,6 ГБ», полоса 3 px, под ней «62%» и «Осталось около 2 мин».
   - «2 Разделение по говорящим / Определяет, кто из участников говорит», справа «Следующим» → после старта та же полоса; если говорящие выключены, шага нет.
5. Строка с замком: «Записи расшифровываются на этом компьютере и никуда не отправляются.»
6. Кнопки: второстепенная sm «Отменить загрузку», тихая «Указать файл модели вручную» (сейчас эта возможность спрятана в подсказке).

Размер и остаток считаем на клиенте: событие `download_progress` уже присылает `[current, total]`; скорость = сглаженная разница за 2-3 с, «Осталось около N мин» показываем после 3 с загрузки. Бэкенд не трогаем. Шаг определяется в view-model (какая модель качается сейчас).

Нет интернета: вместо модального окна та же колонка: иконка, «Нет подключения к интернету», «Модели скачиваются один раз, и для этого нужен интернет. Проверьте подключение и попробуйте еще раз.», главная «Повторить» + тихая «Указать файл вручную».

Слияние: `pages/setup/page.tsx` апстрим меняет редко, view-model трогаем минимально (новое состояние `step`, `bytes`). Лучше вынести разметку в `lib/tyto/setup-steps.tsx`, а в page.tsx оставить одну строку подключения. Стоимость: средняя.

## Диалог экспорта

Порядок решений человека: **что** → **в каком формате** → **как оформить** → сохранить. Сейчас формат стоит первым, а «что» спрятано в тесный переключатель «Транскрипция / Сводка», который не помещается.

Слева колонка 420 px:
1. **Что сохранить**: две карточки-радио рядом (фон прозрачный — фон окна, текст цвета текста, граница 1 px, выбранная обведена цветом текста; в обеих темах контраст текста ≥ 4.5:1 — v3: в макете карточки были нечитаемы из-за конфликта стилей страницы предпросмотра):
   «Расшифровку / Весь разговор с именами и временем» и «Сводку / Главное: решения и задачи». Если сводки нет, карточка серая, описание «Сначала создайте сводку».
2. **Формат** (v2, по просьбе владельца): CSV убран совсем. Две равные колонки по 4 радио-строки 32 px с расширением справа серым:
   - Документ: PDF, Word (DOCX), Простой текст (TXT), Markdown (MD)
   - Субтитры и веб: Веб-страница (HTML), Субтитры (SRT), Веб-субтитры (VTT), Данные (JSON)
   Обе колонки в одной CSS-сетке (`grid-template-columns: 1fr 1fr`, ряды 24 + 4 × 32 px, зазор колонок 24 px), поэтому строки совпадают по высоте и базовой линии. Радио стоят на левом крае группы (подсветка выбранной строки выходит на 8 px за край).
   Под списком одна строка описания выбранного формата (уже есть `exportFormat*Description`).
3. **Оформление** (v2, по просьбе владельца): четыре одинаковые строки-галочки на одной сетке (галочка 16 px, зазор 8, подпись; каждая строка 32 px, общий левый край подписей): «Имена говорящих», «Время каждой реплики» (для SRT/VTT отмечена, заблокирована, подпись «нужно для субтитров»), «Темная тема документа» (вместо переключателя «Светлая / Темная», только для PDF, HTML, DOCX), «Текст справа налево» (тем же размером, что остальные; для русскоязычных почти не нужна, но функция остается). Справа у строк ничего нет, поэтому нет вопроса, на каком уровне стоит контрол.

Справа предпросмотр на сером фоне в виде листа документа (белый лист, тонкая рамка, легкая тень). Подпись «Предпросмотр».

Шапка: «Экспорт» + название записи и длительность (вместо «Выберите, что экспортировать и как это использовать.»).
Подвал: слева имя будущего файла с иконкой («Планерка отдела продаж.pdf»), справа «Отмена» (тихая), для текстовых форматов «Скопировать текст» (второстепенная), «Сохранить PDF» (главная, формат в подписи).

Слияние: `transcript-export-dialog.tsx` уже сильно наш (Tyto переписал его), конфликты в нем ожидаемы в любом случае. Стоимость: средняя. Логика и пропсы не меняются, только разметка; нужны новые ключи `exportContentTranscriptDescription`, `exportContentSummaryDescription`, `exportSummaryUnavailable`, `exportSaveAs` (`Сохранить {format}`), `exportFormatGroupDocument`, `exportFormatGroupWeb` («Субтитры и веб»), `exportDarkTheme` («Темная тема документа»). CSV убирается из списка форматов в диалоге (если формат есть в `use-transcript-export.ts`, код экспорта можно оставить, просто не показывать).

## Тексты

Голос: спокойный деловой русский, на «вы», без эмодзи, без «!», без длинных тире, «е» вместо «ё» допустимо. Одно слово для одного понятия:
- предмет: **расшифровка** (не «транскрипция», не «транскрибирование»);
- действие: **расшифровать**, процесс: «Расшифровываем…»;
- краткое содержание: **сводка** (сейчас в одном месте «Сводка», в другом «Саммари», в третьем «Суммаризация»);
- «видеокарта / процессор» вместо «GPU / CPU» в сообщениях для людей.

## ИИ через прокси-сервис (функция, утверждено 2026-10-25)

Пользователи покупают токены у посредников, которые дают адрес и ключ. Пример инструкции такого сервиса: Base URL `https://<сервис>/v1` (формат OpenAI) и тот же адрес без `/v1` (формат Claude/Anthropic).
- В «ИИ-ассистент → Платформа» новый пункт **«Через прокси-сервис»**: поля «Адрес API», «Ключ», «Модель», подсказка «Вставьте адрес и ключ из инструкции вашего сервиса».
- Формат запросов: если адрес оканчивается на `/v1` — OpenAI (`/chat/completions`), иначе Claude (`/v1/messages`). Рядом переключатель «Формат: OpenAI / Claude», который автоматически выставляется по адресу и может быть изменён вручную.
- У платформы **Claude** появляется поле «Адрес API» (по умолчанию `https://api.anthropic.com`) — сейчас адрес зашит в `lib/ai/client.ts`.
- «Проверить подключение» работает для нового пункта так же.
- Ключ хранится там же, где ключи других платформ.

## Попутные находки

- На пустом экране язык по умолчанию «английский». Для русскоязычных людей это ошибка: по умолчанию нужен «Определить автоматически» или язык системы.
- В диалоге экспорта «Копировать» скрыто для PDF/DOCX/HTML без объяснения; в новой раскладке подвал честно показывает, что доступно.
- В `.dark`/светлом блоках theme.css уже есть проверка `theme.test.ts` на одинаковый набор токенов: новые токены (`--tyto-r-*`, `--tyto-ease`) добавлять в оба блока или в отдельный `:root`-блок, не зависящий от темы.
- Ключи меняются только в `ru-RU.json`; новые ключи нужно добавить и в `en-US.json` (paraglide берет его как запасной).
