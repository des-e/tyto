## Что умеет

- Расшифровывает аудио и видео локально, с помощью Whisper. Файлы не покидают компьютер.
- Подписывает реплики по говорящим: «Говорящий 1», «Говорящий 2» и так далее.
- Встроенный плеер: нажали на реплику и сразу перешли к этому месту записи.
- Текст расшифровки можно править прямо в окне.
- Выгружает результат в TXT, MD, SRT, VTT, HTML, JSON, DOCX и PDF.
- Делает ИИ-сводку через ваш собственный ключ или прокси.
- Обновляется сам.
- Работает на Windows (x64) и macOS (универсальная сборка для Intel и Apple Silicon).

## Приватность

Записи остаются на вашем компьютере. Единственное исключение: если вы включили ИИ-сводку, текст расшифровки отправляется в выбранный вами сервис. Звук и видео не отправляются никогда. Подробнее в [PRIVACY.md](PRIVACY.md).

## История

Tyto вырос из транскрибатора, который я начал делать в апреле 2026 года для своей команды: локальная расшифровка созвонов через Whisper, история записей, плеер с переходом по времени, правка текста и анализ разговора.

Первые версии работали в браузере и запускались из командной строки. Людям это было неудобно: сложная установка, отдельная вкладка, непонятные окна. Поэтому вторая версия стала настоящей программой для Windows и macOS: обычный установщик, свое окно, обновления в один клик.

Для этого я взял за основу открытый проект Vibe и доработал его под свои задачи: свой интерфейс и тексты, разметка говорящих по умолчанию, ИИ-сводка через прокси. Дальше в планах темы разговора с таймкодами.
